# FurryUp Battle Simulator

퍼리업 전투 기획을 빠르게 검증하기 위한 브라우저 기반 팀 전투 시뮬레이터입니다.

## Live demo

https://kimkumo.github.io/FurryUp-BattleSimulator/

## 주요 기능

- 42종 캐릭터 도감 기반 팀 편성
- 팀별 1~5명 전투
- 체력, 공격력, 방어력, 속도, 우선도 편집
- 한 행동 진행, 자동 전투, 배속, 초기화
- 피해 공식, 투지, 회피율, 최대 턴, 난수 시드 변경
- 리메이크 문서에 기재된 캐릭터 능력치·역할·패시브·스킬 반영
- PDF 전투 시퀀스 기반 발동 시점과 턴 종료 상태 피해 처리
- 턴별 행동 로그와 결과 비교

리메이크 문서에서 아직 정의되지 않은 캐릭터의 스킬만 임시로 방어 무시 고정 피해 2를 사용합니다.
